# CodeAlpha_packetSniffer
This is a python script for capturing packets and extracting the source IP, destination IP, protocol type, port numbers, details and payload. It uses scapy to capture packets, it extracts the needed information and stores into a csv file named packet_log.csv

#Running the script
Save into a folder
Open command prompt in the folder
run the command "python Sniffer.py" and hit enter
Press "q" to quit at any point

#Files created
captured_packets.pcap file will be created
packet_log.csv file will be created
